# Лабораторна робота №3: Створення графів та алгоритми їх обходу

Цей репозиторій містить реалізацію базових алгоритмів обходу графів мовою Java.
Проект виконано в рамках дисципліни "Основи алгоритмів".

##  Реалізовані алгоритми
В класі `Lab3Graphs.java` реалізовано:
1. **Обхід у глибину (DFS)** — рекурсивний підхід.
2. **Пошук кількості зв'язних компонент** — на базі алгоритму DFS.
3. **Обхід у ширину (BFS)** — ітеративний підхід з використанням структури даних `Queue` (Черга).
4. **Пошук найкоротшого шляху** — знаходження маршруту між двома заданими вершинами у незваженому графі на базі BFS.
